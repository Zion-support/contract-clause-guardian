## Features
- **Clause risk flags** — Detects indemnity, unlimited liability, auto-renewal and unusual termination clauses.
- **Missing-term checklist** — Compares against a standard playbook: DPA, SLA, exit assistance, IP ownership.
- **Renewal trap radar** — Surfaces notice windows and price-escalation language with plain-English summaries.
